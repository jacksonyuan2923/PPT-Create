# V4.0 四级差异验收标准

等级差异必须同时体现在设计基因、策略权限、量化指标和人工观感上。只改变字体数量或圆角开关，不算通过。

## 1. 设计基因矩阵

| 维度 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| 设计原则 | 原文转写 | 结构建立秩序 | 结论先行 | 主题叙事 |
| 叙事节奏 | 平稳线性 | 对称章节 | 结论—证据—行动 | 情境—转折—收束 |
| 信息密度 | 最高 | 中高 | 中等 | 低密主视觉 |
| 构图 | 文本流 | 对称网格 | 专业网格 + 单一中心 | 非对称 + 跨页呼应 |
| 对象语言 | 无装饰 | 直角模块 | 圆角/轻阴影/图表 | 纹理/蒙版/异形 |
| 标志动作 | 完整文段 | 页眉页脚/编号 | 主结论/主数字 | 视觉锤/叙事节点 |

## 2. 量化阈值

| 指标 | L1 | L2 | L3 | L4 | 验收 |
|---|---:|---:|---:|---:|---|
| 字体家族上限 | 1 | 2 | 3 | 4 | 逐级不减少 |
| 声明的色板规模 | 2 | 5 | 8 | 12 | 精确匹配 |
| 动画强度 | none | minimal | structured | cinematic | 逐级增强 |
| 单页对象动画 | 0 | ≤1 | ≤3 | 按叙事 | 不得越级 |
| 视觉相似度 | — | L1-L2 < .70 | L2-L3 < .60 | L3-L4 < .50 | 相邻阈值 |

视觉相似度计算：

```text
0.50 × 配色余弦
+ 0.15 × 字体重合
+ 0.15 × 文本密度接近度
+ 0.20 × 结构接近度
```

配色权重最高，因为配色和明暗关系最直接决定“看起来是不是同一档”。

## 3. 人工验收

### L1

- 纯白背景、纯文本、无卡片、无装饰色块、无动效。
- 原文完整，阅读顺序稳定。
- 看起来像“结构清楚的文档转幻灯片”，这是正确结果。

### L2

- 统一页眉页脚、章节编号和对称分栏。
- 直角卡片和标准图文框形成规范秩序。
- 没有数据看板、非对称艺术构图、图片蒙版或主题叙事。

### L3

- 每页能一句话指出主结论或主数字。
- 数据、流程、时间、案例分别使用匹配版式。
- 相邻页不连续重复同一骨架。
- 只有一个柔和阴影体系，没有拼贴与纹理。

### L4

- 一眼能识别同一主题系统。
- 封面、章节、内容、收尾存在跨页视觉呼应。
- 信息密度有起伏，不是每页“深色背景 + 大字”。
- 主题效果不牺牲文字可读性和事实证据。

## 4. 测试命令

```bash
python scripts/level_profiles.py
python scripts/level_smoke_test.py work/level-smoke --json work/level-smoke.json
python scripts/check_pptx.py --compare L1.pptx L2.pptx L3.pptx L4.pptx
```

任一项相似度超阈值、策略边界违规或动态权限错误，整体验收失败。
