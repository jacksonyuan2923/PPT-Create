# V4.0.0 分策略设计系统

本文件定义四个内容表达策略的字体、网格、配色、组件与视觉约束。实际生成值以 `scripts/level_profiles.py` 为唯一机器可读来源，本文用于设计判断和技术实现说明。

## 1. 字体系统

### L1 信息优先

- 字体家族：1 种系统无衬线字体，推荐 Microsoft YaHei。
- 层级：2 级。
- 页面标题：30pt，粗体，行距 1.15。
- 正文：17pt，常规，行距 1.30。
- 元数据：12pt。
- 禁止：多字体混排、艺术字、渐变字、阴影字、纹理字、竖排。

### L2 结构优先

- 字体：正式无衬线组合，最多 2 个字体家族；中文使用 Microsoft YaHei，英文与数字可使用 Arial。
- 主层级：3 级。
- 页面标题：34pt，粗体，行距 1.12。
- 模块标题：20pt，半粗，行距 1.20。
- 正文：16pt，常规，行距 1.28。
- 页眉页脚/注释：10pt。
- 禁止：书法标题、全屏蒙版标题、多种装饰字体。

### L3 专业视觉设计

字体角色固定为“标题 + 正文 + 数字等宽”，最多 3 个实际字体家族：

| 层级 | 字体角色 | 字号 | 字重 | 行距 |
|---|---|---:|---|---:|
| 主标题 | 标题字体 | 36pt | Bold | 1.12 |
| 模块标题 | 正文字体 | 22pt | Semibold | 1.18 |
| 正文 | 正文字体 | 16pt | Regular | 1.26 |
| 注释 | 正文字体 | 11pt | Regular | 1.20 |

数字、百分比、日期和代码使用 Consolas，避免比较列的数字宽度漂移。禁止书法标题、渐变字和纹理字；阴影只允许用于组件容器，不用于文字。

### L4 主题叙事

- 基础层级：标题、导语、章节标题、正文、注释，共 5 级。
- 允许主题化字体组合与有限字体视觉化，但不得超过策略配置的字体上限。
- 科技发布可使用无衬线 + 等宽组合；轻奢与文化分支可使用宋体/设计型标题；正文必须保持可读。
- 允许渐变、阴影、描边、纹理和竖排点缀，但必须服从统一艺术指导，不得每页换一种效果。

## 2. 网格与间距

| 策略 | 列数 | 外边距 | 栏间距 | 组件圆角 | 阴影 |
|---|---:|---|---:|---:|---|
| L1 | 2 | 0.72in | 0.40in | 0 | 无 |
| L2 | 12 | 0.68in | 0.22in | 直角 | 无 |
| L3 | 12 | 0.72in | 0.20in | 0.12in | 单一柔和环境阴影 |
| L4 | 12 | 0.50in | 0.24in | 按主题 0.12–0.20in | 主题统一控制 |

### L3 12 列网格计算

画布宽度 13.333in，左右边距各 0.72in：

```text
content_width = 13.333 - 0.72 - 0.72 = 11.893in
column_width = (11.893 - 0.20 × 11) / 12 = 0.80775in
```

标题、关键面板、图表、案例图和表格必须对齐 12 列边线。允许 0.08in 的实现误差。正文文本框可在组件内部使用一致内边距，但组件容器必须回到列线。

### L3 圆角与阴影

- 组件圆角：0.12in，仅用于指标卡、流程节点、案例图框和表格容器。
- 阴影：单一柔和环境阴影，黑色透明度约 12%，模糊半径 12pt，距离克制。
- 同一页不得出现多种阴影风格；线条、按钮感组件和纯文本区域不加阴影。
- 卡片不是默认版式。只有指标、流程节点、可并列模块才使用卡片。

## 3. 色彩系统

### L1

- 背景 `#FFFFFF`
- 正文 `#111111`
- 次级文字 `#555555`
- 分隔线 `#B8B8B8`
- 不主动设置品牌强调色；如需强调只使用灰阶字重变化。

### L2

- 背景 `#FFFFFF`
- 面板 `#EEF3F8`
- 正文 `#10263B`
- 次级文字 `#4A647A`
- 强调 `#1F5FA8`
- 分隔线 `#B7CADB`

### L3

- 背景 `#F5F7FA`
- 面板 `#FFFFFF`
- 正文 `#122033`
- 次级文字 `#5D6B7A`
- 强调 `#0B7A75`
- 分隔线 `#C8D2DC`
- 对比深色 `#08131F`
- 高亮浅色 `#DCEFEB`

禁用高饱和霓虹全屏背景。颜色用于建立重点和状态，不用于随机分类。

### L4 四类主题色

| 分支 | 背景 | 强调 | 说明 |
|---|---|---|---|
| 科技发布 | `#071016` | `#22D3EE` | 深色、精确线路和产品信号 |
| 轻奢品牌 | `#F4EFE6` | `#B48A4A` | 暖中性、大留白、克制品金 |
| 文化文创 | `#F3EDE2` | `#A44A32` | 纸张中性、现代文化符号 |
| 产品路演 | `#F7F5F2` | `#E84855` | 清晰产品层级和跨页记忆色 |

正文与背景对比度目标不低于 4.5:1，大标题和关键数字不低于 3:1。图片上覆盖文字必须使用可靠蒙版或局部底色。

## 4. 组件权限

### L1

允许：

- 标题
- 项目符号 / 原始段落
- 默认分隔线
- 必要的直接图片
- 基础原生图表

禁止：

- 卡片、圆角容器、图标、数据看板、流程、时间轴、蒙版、拼贴、装饰色块。

### L2

允许：

- 标题栏、章节编号、固定页眉页脚
- 直角基础卡片
- 标准图文框
- 极简图标
- 对称对比、标准图表、表格

禁止：

- 数据看板、流程时间轴、图片蒙版、拼贴、定制信息图、非对称构图。

### L3

允许：

- 结论页
- 指标卡
- 数据看板
- 步骤条
- 时间轴
- 架构对比
- 案例图文
- 章节过渡
- 图标文字模块
- 专业图表、标准表格

禁止：

- 厚重纹理、编辑式拼贴、跨页自由叙事、多种阴影共存。
- 把普通并列说明全部包装成卡片墙。

### L4

允许：

- 沉浸式主视觉、编辑式拼贴、跨页视觉符号、定制信息图、主题纹理、产品路演页。
- 可复用 L1–L3 的基础信息结构，但整体必须保留主题视觉系统。

禁止：

- “高级感”仅由深色、金色或大字堆出。
- 风格与主题不符，生成素材被伪装成真实事实证据。

## 5. 图片系统

- L1：原始比例 contain，无边框、圆角、蒙版或滤镜。
- L2：标准 framed image，等比裁切，统一边框。
- L3：用于案例、产品、人物、证据或场景；可使用克制圆角和局部蒙版。全屏背景只用于封面/过渡。
- L4：根据主题分支选择编辑式裁切、沉浸大图和多图叙事；必须保持主体和证据完整。

每张图片必须回答“它支持哪个观点”。不能用随机办公图、通用机器人图、抽象粒子图填充。

## 6. 图表系统

| 策略 | 默认图表 | 标签 | 图例 | 网格 | 特效 |
|---|---|---|---|---|---|
| L1 | 基础柱/线/表 | 可选 | 需要时保留 | 可保留 | 无 |
| L2 | 柱/条/线/饼/表 | 通常关闭 | 保留 | 关闭 | 无 |
| L3 | 柱/线/环/子弹/表 | 开启 | 通常关闭 | 轻量 | 无渐变、无发光 |
| L4 | 主题化柱/线/环/定制信息图 | 开启 | 按叙事决定 | 关闭 | 统一主题效果 |

所有策略：

- 数值轴从 0 开始，除非有明确且合理的技术原因。
- 图表标题表达结论。
- 标明单位、范围、比较口径和数据来源。
- 不把预测、示意、假设与真实数据混为一谈。

## 7. 技术实现约束

默认调用：

```python
from level_profiles import get_profile, font_stack, resolve_layout
from leveled_pptx import LeveledDeckBuilder

profile = get_profile("L3")
layout = resolve_layout("L3", content_type="process", has_data=False)
builder = LeveledDeckBuilder("L3")
builder.add_process_steps(...)
```

L4：

```python
builder = LeveledDeckBuilder("L4", style_branch="luxury_brand")
```

新增组件必须：

1. 读取 `LevelProfile` 的字体、网格、颜色和组件权限。
2. 通过 `_assert_layout()`、`_assert_component()` 阻止越级渲染。
3. 在 `slide_audit` 记录版式、内容类型、组件和风格分支。
4. 通过 `level_smoke_test.py` 和 `check_pptx.py --level` 回归。

## 8. V4.0 设计基因与色板系统

V4 不再只通过“允许哪些组件”区分等级。`LevelProfile` 同时包含：

- `design_gene`：设计原则、叙事节奏、信息密度曲线、构图签名、视觉中心规则、对象性格、留白方式和标志动作。
- `palette_system`：主色、辅助色、中性色、功能色、最大色数和使用比例。
- `animation`：转场、对象动画、强调/退出/路径、触发、媒体、密度、时长和错峰。

| 等级 | 色板规模 | 设计基因 | 动效强度 |
|---|---:|---|---|
| L1 | 2 | 原文转写、零装饰、线性阅读 | none |
| L2 | 5 | 对称网格、章节化商务秩序 | minimal |
| L3 | 8 | 结论先行、单一视觉中心、证据可视化 | structured |
| L4 | 12 | 主题叙事、跨页视觉锤、编辑式构图 | cinematic |

L1 黑灰色阶在生成器中仍可实现可读的灰阶文字和分隔线，但声明的装饰色板严格只有黑与白；模板迁移不允许向 L1 注入品牌强调色。

设计基因不是说明文字。生成器在每页审计中写入 `design_principle` 与 `composition_signature`，`check_pptx.py` 用视觉中心、网格、版式多样性和动画权限做反向验证。
