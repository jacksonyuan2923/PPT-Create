# V4.0.0 内容表达策略与版式引擎

V4.0.0 将 L1–L4 定义为四种并列的设计基因和内容表达策略。等级不是视觉高低，也不是“装饰数量”刻度。选择依据是演示目的、受众、信息结构和场景。

机器可执行参数以 `scripts/level_profiles.py` 为准；本文件说明策略选择、版式任务、视觉中心和评分方式。

## 1. 策略选择

| 等级 | 表达策略 | 核心目标 | 典型场景 | 不应使用的情况 |
|---|---|---|---|---|
| L1 | 基础信息表达 · 信息优先 | 最低成本完成准确、高效的信息传递 | 原始资料留档、草稿、快速作业 | 需要正式商务结构或重点可视化时 |
| L2 | 规范商务表达 · 结构优先 | 用标准结构建立正式感与阅读效率 | 部门汇报、项目申报、内部评审 | 需要强论点包装或沉浸主题时 |
| L3 | 专业视觉设计 · 重点强化 | 用专业可视化强化核心论点 | 项目汇报、方案评审、经营分析、客户提案 | 只需逐字转写、不应对内容做重点提炼时 |
| L4 | 高端定制设计 · 主题叙事 | 建立完整主题叙事与强识别视觉系统 | 科技发布、轻奢品牌、文化文创、产品路演 | 频繁内部沟通、持续高成本维护不具性价比时 |

选择步骤：

1. 明确演示要解决的任务：完整留档、建立标准化结构、突出关键论点或构建主题叙事。
2. 验证受众与使用场景是否支持该策略。
3. 检查原始信息是否允许提炼。L1 必须保留原文；L2 做结构组织；L3 可结论先行并提炼关键词；L4 可将长内容拆到辅助页。
4. 在生成前调用 `get_profile()`、`font_stack()`、`resolve_layout()` 和必要的 `resolve_style_branch()`。

用户未指定策略时，主动说明四种选项及推荐理由并请求确认。不得把 L4 设为默认目标。

## 2. 四级版式白名单

白名单是生成权限，不是建议清单。`LeveledDeckBuilder` 对不允许的版式或组件应直接拒绝。

### L1 信息优先

允许：

- `title_body`：标题 + 项目符号/段落。
- `simple_split`：简单左右或上下分栏。

禁止：

- 卡片、圆角组件、图标模块、数据看板、流程、时间轴、图片蒙版、拼贴、非对称艺术构图。
- 纯装饰色块、背景图、渐变、阴影和创意图形。

视觉目标是可读和完整，而不是建立视觉中心。允许长页，但不得裁切、删减或改写字义。

### L2 结构优先

允许：

- `title_band`
- `structured_title_bar`
- `symmetric_columns`
- `structured_cards`
- `framed_image_text`
- `structured_table`
- `numbered_section`
- `structured_summary`

使用规则：

- 12 列网格、固定页眉页脚、统一章节编号。
- 卡片为直角基础框，不使用大圆角或悬浮阴影。
- 图片采用标准边框和等比裁切。
- 图表保留单位、图例和比较口径，不使用装饰性特效。

### L3 重点强化

L3 是专业职场场景的默认核心策略，重点是版式任务匹配和重点层级，不是“卡片越多越好”。

| 版式 | 内容任务 | 视觉中心 | 必检项 |
|---|---|---|---|
| `key_conclusion` | 先给结论，再给证据 | 主结论句 + 2–3 条证据 | 证据必须支持结论，不重复标题 |
| `metric_cards` | 3–4 个并列关键指标 | 指标值 | 数值、单位、口径、时间范围 |
| `data_dashboard` | 关键指标与趋势关系 | 主图表或主指标 | 零基线、数据标签、来源与范围 |
| `process_steps` | 3–5 个连续步骤 | 当前/关键步骤 | 顺序、输入输出和责任边界 |
| `timeline` | 阶段、里程碑与变化 | 主轴和关键节点 | 时间尺度真实，非线性需注明 |
| `architecture_compare` | 现状与目标、方案 A/B | 差异列 | 对比维度一致，连接关系可追踪 |
| `case_visual` | 挑战—行动—结果 | 主图或结果证据 | 图片与案例一致，不伪造场景 |
| `section_transition` | 章节切换与叙事停顿 | 章节标题/大图 | 不连续插入空章节页 |
| `icon_text_modules` | 2–4 个能力或模块 | 模块标题 | 图标只辅助识别，不承担含糊语义 |
| `image_text_split` | 图文解释或场景说明 | 相关主图 | 主体不被裁切，文字区对比稳定 |
| `chart_analysis` | 单一数据论点 | 主图表 | 图表标题即结论，单位与来源完整 |
| `standard_table` | 多字段精确比较 | 行/列重点 | 字号可读，行高统一 |
| `action_summary` | 结论和下一步 | 行动主线 | 不再引入无证据的新观点 |

L3 版式要求：

- 12 列网格，统一外边距、栏间距和组件圆角。
- 相邻页不得连续使用同一主版式超过 2 页。
- 每页只有一个主视觉中心。
- 数据组件旁必须有口径或来源；案例图必须对应案例对象。
- 可使用圆角和单一柔和环境阴影，但不得叠加多种阴影、发光或装饰材质。

### L4 主题叙事

L4 允许使用低等级的基础结构作为信息承载，但整页、整套仍必须体现统一艺术指导。允许：

- `custom_cover`
- `full_bleed_story`
- `editorial_collage`
- `asymmetric_narrative`
- `texture_collage`
- `immersive_section`
- `custom_infographic`
- `narrative_timeline`
- `product_roadshow`
- `narrative_closing`

无论选择哪条 L4 分支，都必须先定义主题视觉系统：色彩、字体、图像、图形、节奏、封面到结尾的跨页呼应。不能只用深色背景或书法字体冒充定制设计。

## 3. L4 四类高端风格语言

### 科技发布

- 构图：深色空间、水平信号线、产品细节特写、节点式信息层级。
- 图像：产品渲染、界面细节、系统关系示意。生成图不得伪装为真实产品。
- 图形：精确线条、状态节点、克制的动态暗示。
- 禁止：廉价蓝紫渐变、随机粒子、无关机器人插画。

### 轻奢品牌

- 构图：大留白、非对称静物、精细裁切、跨页材质呼应。
- 图像：产品、材质、工艺和真实空间。
- 图形：细线、暖金属小面积点缀、低饱和面板。
- 禁止：大面积金色铺底、厚重欧式花纹、拥挤卖点墙。

### 文化文创

- 构图：现代横排编辑结构，可用局部竖排点缀，但主体信息保持可读。
- 图像：实物、工艺、人物和场域；必须尊重文化语境和版权。
- 图形：从内容中提炼的现代文化符号与纹样，不做默认国风模板。
- 禁止：无来源文物图、伪装手写历史文献、纹样与技术无关的装饰。

### 产品路演

- 构图：产品大图、单点价值主张、跨页记忆色、问题到方案的清晰切换。
- 图像：产品实拍、界面、使用场景和关键细节。
- 图形：一致的产品标注、演示序列和跨页色块。
- 禁止：虚构功能界面、通用 Startup 模板、无序功能卡片墙。

## 4. 设计方向与版式授权

通用设计方向仍可提供创意参照，但不能覆盖策略边界。

| 方向 | 适配策略 | 主要价值 |
|---|---|---|
| 简洁信息图 | L1–L3 | 快速阅读、任务清晰 |
| 正式商务 | L2–L3 | 规范结构、稳定阅读 |
| 科技产品 | L3–L4 | 系统关系、产品价值 |
| 咨询分析 | L3 | 结论先行、证据链 |
| 杂志编辑 | L3–L4 | 节奏变化、图文咬合 |
| 沉浸叙事 | L4 | 主题识别和情绪推进 |
| 轻奢精品 | L4 | 材质、留白和克制质感 |
| 文化叙事 | L4 | 文化语境和视觉转译 |

同一个需求只选择一个主方向，最多融合一个辅助方向。方向不能绕过等级白名单。

## 5. 逐页设计规划

生成前必须保存 `design_plan.md`，逐页记录：

| 字段 | 要求 |
|---|---|
| 页码与页面角色 | 封面、结论、数据、流程、案例、章节、总结 |
| 表达任务 | 该页要完成的理解、比较、证明或叙事动作 |
| 观众结论 | 看完后应记住的一条结论 |
| 内容证据 | 支撑结论的事实、数据、原文或素材 |
| 内容类型 | metrics / data / process / timeline / architecture / case / table / narrative |
| 策略版式 | `resolve_layout()` 返回的白名单版式 |
| 视觉中心 | 主结论、主数字、主图、主图表或关键差异 |
| 组件 | 数据卡、步骤条、时间轴、图标文字模块等 |
| 素材来源 | 文件、数据、图片、原生图表或原创图示 |
| 节奏 | 与相邻页的密度、明暗、构图差异 |

检查：

- 每页是否只有一个主结论。
- 证据类型与版式是否匹配。
- 组件是否有信息任务。
- 相邻页是否机械复用同一骨架。
- L1 是否保留了原始信息，L2 是否维持正式结构，L3 是否强化重点，L4 是否形成主题系统。

## 6. 素材、图表与信息图

素材选择优先级：

1. 用户提供的品牌、产品和业务素材。
2. 可合法获取且与主题直接相关的真实素材。
3. 环境明确支持时生成原创抽象视觉；不得当作真实事实证据。
4. 无合适图片时，使用原生图表、可编辑图示或留白。

图表基本规则：

- 柱状/条形图从零开始。
- 标题写结论，不写“数据展示”。
- 标明单位、时间范围、样本量和来源。
- 一个图表只讲一个主关系。
- 区分预测、假设和实际数据。

## 7. 策略匹配度评分

不再使用统一的“美观度加分”或逐级升高的分数区间。四个策略都使用 100 分制，最低通过分为 80；不同等级使用不同维度，证明“场景匹配”。任一硬边界违规时，无论总分多少都不得判定通过。

### L1 信息优先

| 维度 | 分值 |
|---|---:|
| 信息完整度 | 30 |
| 可读性 | 25 |
| 基础结构 | 15 |
| 基础版式执行 | 10 |
| 策略边界 | 10 |
| 执行准确性 | 10 |

### L2 结构优先

| 维度 | 分值 |
|---|---:|
| 结构匹配 | 20 |
| 内容组织 | 20 |
| 正式一致性 | 20 |
| 层级清晰度 | 15 |
| 商务组件 | 15 |
| 执行准确性 | 10 |

### L3 重点强化

| 维度 | 分值 |
|---|---:|
| 重点突出度 | 25 |
| 逻辑可视化 | 20 |
| 版式丰富度 | 15 |
| 信息层级 | 15 |
| 商务专业度 | 15 |
| 执行准确性 | 10 |

### L4 主题叙事

| 维度 | 分值 |
|---|---:|
| 主题叙事 | 25 |
| 视觉系统 | 20 |
| 构图创新 | 20 |
| 跨页一致性 | 15 |
| 信息支撑 | 10 |
| 执行准确性 | 10 |

评分时先做硬边界检查，再逐维度打分。L1 的“完整原文”不是缺点；L4 的“低文字密度”也不能弥补主题不一致或信息无法支撑。

## 8. 反向失职检查

除越级美化外，还必须检查低等级是否为了视觉化而牺牲任务目标：

- L1：是否删减原文、任意概括、拆成空泛关键词、加入卡片或装饰导致阅读路径破碎。
- L2：是否跳过章节结构、破坏对称网格、用 L3/L4 组件制造过度视觉包装。
- L3：是否只换深色主题但未强化重点、图表没有结论、页面组件化却不表达逻辑。
- L4：是否只有视觉风格，没有贯穿主题；是否存在与内容不符的素材或叙事。

任何反向失职都计为策略匹配失败，不得用“平均分合格”掩盖。

## 9. V4.0 视觉差异引擎

四级的页面生成不再共享同一排版内核后只切换权限。每级由 `DesignGene` 提供不同的构图决策：

1. L1 先保证阅读顺序和原文完整，再决定是否分栏。
2. L2 先把内容映射到章节、标题带和对称列，再决定卡片数量。
3. L3 先从证据中确定唯一主结论或主数字，再选择指标、看板、流程、时间轴或案例版式。
4. L4 先确定主题视觉系统和叙事节点，再用封面、编辑构图、沉浸图文、章节和收尾形成跨页呼应。

L3 视觉中心检查会忽略纯背景与装饰面板，只比较有语义的文字、图片、图表和表格。L4 需要通过主题色、视觉锤、构图节奏和跨页符号建立一致性。

视觉相似度以配色为最大权重，其次比较字体、文本密度和结构。相邻等级阈值：

| 相邻等级 | 最大相似度 |
|---|---:|
| L1–L2 | 0.70 |
| L2–L3 | 0.60 |
| L3–L4 | 0.50 |

相似度超过阈值时，优先重做构图与配色逻辑，不要只增加装饰或动画。
